# Database

Route22 and ZAtours share the OpDesk Supabase project (opdeskver2). All
directory tables are prefixed `dir_` and were applied as migrations
`directory_core` and `directory_route22_extras` on 1 Oct 2026.

`schema.sql` is the ORIGINAL standalone Route22 schema, kept for reference
only. Do not run it against opdeskver2.
